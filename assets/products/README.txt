CÓMO SUBIR LAS FOTOS DE LOS PRODUCTOS
======================================

Cada perfume tiene su propia subcarpeta dentro de assets/products/.
Solo tienes que dejar caer una foto del producto dentro de la carpeta
correspondiente y refrescar el navegador (F5) — la web la detecta sola.

NOMBRES DE ARCHIVO ACEPTADOS (en orden de prioridad)
----------------------------------------------------
La web busca, en cada carpeta, los siguientes nombres:

  1. <slug>.jpg / .jpeg / .png / .webp / .avif
     Ej: assets/products/sauvage/sauvage.jpg
  2. main.jpg / .png / .webp / ...
     Ej: assets/products/sauvage/main.jpg
  3. 1.jpg / .png / ...
     Ej: assets/products/sauvage/1.jpg
  4. foto.jpg / producto.jpg / ...

La primera que encuentre, la usa.

RECOMENDACIÓN DE FORMATO
------------------------
- Fondo transparente PNG (queda mejor sobre el negro de la web)
- Si es JPG: fondo oscuro o negro
- Proporción 3:4 (vertical), 800×1066 px o superior
- Si tienes WEBP, mejor (más ligero)

ALTERNATIVAS
------------
1. Si prefieres no andar con archivos, usa el botón ⚙ flotante de la
   web: pegas URLs (de Druni, del fabricante, etc.) y se cargan al
   instante sin necesidad de archivos locales.
2. Si una carpeta no tiene foto, la web muestra el SVG vectorial que
   ya está dibujado a medida para esa marca.
